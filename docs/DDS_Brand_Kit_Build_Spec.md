## 1. Brand Tokens

**Colors**

| Token                       | Hex       | Use                             |
| --------------------------- | --------- | ------------------------------- |
| Teal (primary)              | `#0E9589` | Accents, links, all buttons     |
| Teal (bright, dark bg only) | `#19C3B2` | Accents on dark/navy sections   |
| Ink / near-black            | `#0F172A` | Headings, dark sections, footer |
| Body gray                   | `#5B6675` | Body text                       |
| Muted gray                  | `#8894A3` | Captions, secondary text        |
| White                       | `#FFFFFF` | Backgrounds, text on dark       |
| Light card bg               | `#F5F8FB` | Cards, panels                   |
| Mint accent bg              | `#EAF8F3` | Highlight strips, pills         |

**Typography:** Poppins — weights 400 (body), 500, 600, 700 (headings).

**Buttons:** ONE style sitewide — solid teal `#0E9589`, white text, rounded. Remove all blue/purple/red button variants.

**Logo files** (in the kit): `dds_logo_black.svg`/`.png`, `dds_logo_white.svg`/`.png` (for dark headers/footer), `dds_monogram_black`/`white` (favicon + avatar), `dds_logo_1color_black`.

> ⚠️ The SVGs currently use the older bluer teal `#32B1BC`. Find-and-replace that to `#0E9589` so the logo matches the site palette.
